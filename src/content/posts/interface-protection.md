板子做出来能跑，接上外部设备就烧 IO —— 这类问题十有八九是**保护电路没做**或**电平没匹配**。

## TVS 与 ESD：名字像，用途不同

| | ESD 保护管 | TVS |
|---|---|---|
| 主要目标 | 静电放电（IEC 61000-4-2） | 浪涌/瞬态过压 |
| 响应速度 | 极快（< 1ns） | 快（< 1ns ~ 几 ns） |
| 能量承受 | 小（几 A，8/20µs） | 大（几十 ~ 几百 A） |
| 结电容 | 可以做得很小（< 1pF） | 通常较大 |
| 典型位置 | USB / HDMI / 按键 / 外露 IO | 电源入口、长线接口、继电器 |

实际设计里，**信号线用低电容 ESD 管，电源入口用 TVS**，两者不冲突。

## TVS 的四个参数

选 TVS 只看四个数：

```text
VRWM  反向工作电压（standoff）—— 正常工作时能承受的最高电压
VBR   击穿电压 —— 开始导通的电压
VC    钳位电压（@ Ipp）—— 大电流下的实际电压
Cj    结电容 —— 影响高速信号
```

### 怎么定 VRWM

**VRWM 必须 ≥ 线路最高正常工作电压，通常留 10% 余量。**

- 5V 电源线 → 选 VRWM ≥ 5.5V 的（常见 5.5V / 6V 档）
- 3.3V 信号线 → 选 VRWM ≥ 3.6V 的
- RS485 A/B 线（差分 ±7V 共模） → 选 VRWM ≥ 12V 的

**VRWM 选太低的后果**：正常工作时就漏电、发热、甚至击穿短路，表现为「接上设备就通信异常」。

### VC 决定 IO 会不会被打死

钳位电压 VC 是大电流下的实际电压。**VC 必须低于被保护器件的绝对最大额定值。**

比如 STM32 的 IO 绝对最大是 VDD + 0.3V = 3.6V。如果 TVS 在 5A 时 VC = 9V，那 IO 还是会被打穿。

**所以选 TVS 要看 VC，不只是 VRWM。** 手册里通常给 `VC @ Ipp` 的表格。

### 结电容：高速信号的关键

| 接口 | 允许的 Cj |
|---|---|
| USB 2.0 高速（480Mbps） | < 1pF |
| USB 全速（12Mbps） | < 5pF |
| 以太网 | < 3pF |
| UART / I2C / SPI（< 10MHz） | < 50pF 都无所谓 |
| RS485 / CAN | < 100pF |

用大电容 TVS 保护 USB 高速线，会导致眼图闭合、通信失败。这就是为什么「USB ESD 管」卖得比普通 TVS 贵。

## 3.3V 与 5V 互连：四条路

### 方案一：直接连（只在特定方向可行）

**5V 器件输出 → 3.3V 器件输入**：多数情况下可以。

很多 3.3V MCU 的 IO 是 **5V 容忍（5V tolerant）** 的，手册里标 `FT`（Five-volt Tolerant）。查引脚定义表里的 `FT` 标记。

⚠️ 但要注意：
- **模拟引脚、复用为 ADC 的引脚通常不是 5V 容忍**
- 不是所有 3.3V 芯片都支持，ESP32 **不是** 5V 容忍
- 上电顺序问题：5V 器件先上电，会通过 IO 的 ESD 二极管给 3.3V 供电（反向灌电流），可能导致 3.3V 域"半上电"异常

**3.3V 输出 → 5V 器件输入**：**通常不行**。

5V 器件的 VIH 一般是 0.7×VDD = 3.5V，3.3V 达不到。有些 CMOS 器件 VIH = 0.6×VDD = 3.0V，勉强能用但不保证。

### 方案二：电阻分压（只能单向，且慢）

```text
5V ──[R1 10k]──┬── 3.3V 输入
               │
             [R2 20k]
               │
              GND
```

分压比 = 20/(10+20) = 0.667，5V → 3.33V ✓

**代价**：
- 单向，不能反向
- RC 时间常数限制速度（10k//20k × 10pF ≈ 67ns，超过 1MHz 就明显失真）
- 静态功耗

适合：低速（按键、使能信号、低频 PWM）。

### 方案三：MOS 双向电平转换（推荐）

经典电路，一个 N-MOS + 两个上拉：

```text
3.3V ──[10k]──┬───────────── 3.3V 侧 IO
              │
             ┌┴┐  D
             │ │──┐
             │ │  │
             └┬┘  │
         G ───┤   │
              │   │
             ┌┴┐ ┌┴┐
             │ │ │ │  S
             └┬┘ └┬┘
              │    │
5V ──[10k]────┴────┴──────── 5V 侧 IO
```

（栅极接 3.3V，源极接 5V 侧，漏极接 3.3V 侧的上拉点）

原理：利用 MOS 的体二极管和阈值，**双向、速度快、成本低**（BSS138 几毛钱）。

- 3.3V 侧拉低 → 体二极管先导通 → Vgs 上升 → MOS 导通 → 5V 侧被拉低
- 5V 侧拉低 → 体二极管导通 → 3.3V 侧被拉低
- 空闲时两边都被上拉到各自电平

**适合**：I2C、UART、SPI、GPIO，速度到几 MHz 没问题。

常用器件：**BSS138**（单路）、**TXS0108E**（8 路专用芯片）。

### 方案四：专用电平转换芯片

| 型号 | 路数 | 特点 |
|---|---|---|
| TXS0108E | 8 | 双向，自动方向，最高 60Mbps |
| TXB0108 | 8 | 双向，驱动能力弱（不适合 I2C） |
| 74LVC1T45 | 1 | 单向，带方向脚，速度快 |
| 74HC4050 | 6 | 单向 5V→3.3V，便宜 |

**TXS 系列适合推挽信号**（SPI、UART）；**I2C 是开漏**，要用 TXS（有内部上拉）或直接用 MOS 方案。

## 常用接口的保护配置

### UART / GPIO 引出到接插件

```text
MCU IO ──[串联 100Ω]──┬── 接插件
                     │
                  [ESD 管到 GND]
```

串联电阻限流 + ESD 管泄放。100Ω 对低速信号没影响。

### RS485

```text
A/B 线 ──┬── TVS (VRWM 12V, 双向) ── GND
        └── 共模电感 / 磁珠
        └── 终端电阻 120Ω（只在总线两端）
```

RS485 是**差分 + 长线 + 工业环境**，必须做：TVS + 共模电感 + 终端匹配。便宜的方案常常省掉共模电感，结果在现场被干扰打得很惨。

### CAN

类似 RS485，但注意 **CAN_H/CAN_L 的共模电压范围更宽**，选 VRWM 更高的 TVS。

### USB

D+/D- 用**低电容 ESD 阵列**（Cj < 1pF），VBUS 用普通 TVS。别用错了。

## 自恢复保险丝（PTC）

串在电源入口防短路：

```text
输入 5V ──[PTC 500mA]── 板内电路
```

选型看两个数：
- **保持电流 I_hold**：正常工作不动作的最大电流
- **动作电流 I_trip**：超过就跳开（一般是 I_hold 的 2 倍）

⚠️ PTC 是**热动作**器件，响应慢（几十 ms ~ 几秒），而且**动作后仍有漏电流**。它防的是持续短路，不是瞬态浪涌（那是 TVS 的活）。

## 一份检查清单

```text
□ 所有外露接口（接插件、按键、LED）都有 ESD 保护
□ 电源入口有 TVS + PTC
□ TVS 的 VRWM ≥ 线路最高电压 × 1.1
□ TVS 的 VC < 被保护器件的绝对最大值
□ 高速信号（USB/以太网）用低电容 ESD 管（Cj < 3pF）
□ 5V 器件驱动 3.3V 输入前，确认引脚是 5V 容忍（FT）
□ 3.3V 驱动 5V 输入时做了电平转换
□ I2C 电平转换用了 MOS 方案或 TXS（不是 TXB）
□ 长线接口（RS485/CAN）有共模电感和终端匹配
```

## 小结

接口保护的核心思路是**分层**：

1. **第一层**：PTC / 保险丝 —— 防持续短路
2. **第二层**：TVS —— 防浪涌和瞬态过压
3. **第三层**：串联电阻 —— 限流，给前两层争取时间
4. **第四层**：芯片内部的 ESD 二极管 —— 最后一道，别指望它扛

电平转换记住一句：**5V 输出进 3.3V 要看是不是 FT 引脚；3.3V 输出进 5V 一定要转换。**

这些都做对了，板子才能在实验室之外活下来。
