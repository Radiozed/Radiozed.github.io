LDO 只有三个引脚，看起来比 DC-DC 简单得多。但只要**压差和电流乘起来超过 1W**，它就会变成一个烫手的电阻。

这篇的核心就一个公式：**LDO 把多余的电全部变成热**。

## 一个公式定生死

```text
P_loss = (Vin − Vout) × Iout
```

注意：**和负载功耗无关，只和压差、电流有关**。LDO 的效率是：

```text
η = Vout / Vin
```

| 场景 | 效率 | 评价 |
|---|---|---|
| 5V → 3.3V | 66% | 可接受 |
| 3.7V → 3.3V | 89% | 很好，锂电供电首选 |
| 12V → 3.3V | **27.5%** | 灾难 |
| 24V → 3.3V | **13.8%** | 别想了 |

## 三个真实场景算一遍

### 场景 A：5V → 3.3V @ 200mA

```text
P = (5 − 3.3) × 0.2 = 0.34 W
```

SOT-223 封装的 AMS1117，θJA ≈ 80°C/W（有铜皮散热）：

```text
ΔT = 0.34 × 80 = 27 °C
环境 40°C → 结温 67°C   ✅ 没问题
```

### 场景 B：12V → 3.3V @ 300mA

```text
P = (12 − 3.3) × 0.3 = 2.61 W
```

同样 SOT-223：

```text
ΔT = 2.61 × 80 = 209 °C
环境 40°C → 结温 249°C   ❌ 远超 125°C 上限，必然热保护/烧毁
```

要让它工作，需要 θJA ≤ (125−40)/2.61 ≈ 32°C/W —— 这得用 TO-220 加散热片。**为了省一颗 Buck 而加散热片，毫无意义。**

**结论：12V → 3.3V 必须用 Buck。**

### 场景 C：3.7V 锂电 → 3.3V @ 100mA

```text
P = (3.7 − 3.3) × 0.1 = 0.04 W
ΔT = 0.04 × 250（SOT-23） = 10 °C   ✅ 完全没问题
```

而且锂电从 4.2V 放到 3.0V，最低时 3.0V < 3.3V —— **LDO 会掉出稳压区**。这种情况要用**低压差 LDO**（dropout < 100mV）或者 Buck-Boost。

## 压差（Dropout）也是个坑

LDO 要维持稳压，输入必须比输出高出一个**压差**：

| 型号 | 压差（典型） | 说明 |
|---|---|---|
| AMS1117 | 1.1~1.3V @ 1A | **5V→3.3V 只有 1.7V 余量，满载时会掉压** |
| ME6211 | ~100mV @ 300mA | 锂电应用常用 |
| RT9013 | ~250mV @ 500mA | 通用 |
| TLV70018 | ~170mV @ 200mA | 低功耗，Iq 很小 |

**经典错误**：3.7V 锂电 → 3.3V 用 AMS1117。电池放到 3.5V 时，3.5 − 1.1 = 2.4V，输出掉到 2.4V，MCU 直接复位。

## 那什么时候该用 LDO

不是「小电流就用 LDO」，而是看这三个理由：

### 1. 噪声敏感

LDO 没有开关动作，输出干净。**ADC 基准、射频模块、音频、晶振供电** 优先 LDO。

DC-DC 的纹波通常在 10~50mV，虽然可以用 LC 滤波压下去，但 LDO 的 **PSRR**（电源抑制比）更省事 —— 好的 LDO 在 1kHz 能到 60~80dB。

### 2. 压差小、电流小

3.3V → 1.8V @ 100mA：

```text
LDO：P = 1.5 × 0.1 = 0.15W，效率 55%
Buck：效率约 85%，但要电感电容，成本高、面积大
```

这种场合 LDO 更划算。

### 3. 成本与面积

LDO 只要 1 颗芯片 + 2 个电容，成本几毛钱。DC-DC 要 IC + 电感 + 3~4 个电容，还要布局空间。

## 电源树怎么规划

一个典型带联网的板子：

```text
12V 输入
 │
 ├─ Buck (12V→5V, 2A) ──── USB 输出、继电器、外设
 │
 └─ Buck (12V→3.3V, 1A) ─┬─ 数字 3.3V ── MCU IO、Flash、传感器
                          │
                          ├─ LDO (3.3V→1.8V 或 3.3V→3.0V) ── 模拟部分（ADC 基准）
                          │
                          └─ 磁珠 + 独立 LDO ── 射频/WiFi 模块
```

### 三条原则

**① 先降到一个中间电压，不要每路都从最高压降**

12V 直接降到 1.2V（MCU 核心）效率很低（占空比只有 10%）。先降到 5V 或 3.3V，再二级降。

**② 噪声敏感的部分单独一级**

模拟和射频不要和数字共用一个 LDO，最好各走一路，或者至少中间串磁珠（ferrite bead）。

```text
数字 3.3V ──[磁珠 600Ω@100MHz]── 模拟 3.3V
```

**③ 上电时序**

大多数 MCU 不要求时序，但**带 FPGA / 摄像头 / 多电压系统的板子要**：

- 一般规则：**核心电压先上，IO 后上**（避免 IO 电压高于核心导致闩锁）
- 用带 PGOOD 输出的 DC-DC，串联使能脚实现顺序上电
- 或者用专门的电源时序芯片

## 去耦电容怎么放

每个电源引脚配一个 **0.1µF**（100nF），这是知识，也是肌肉记忆。

```text
MCU VDD 引脚
   │
   ├── 0.1µF ── GND    ← 尽量贴近引脚，走线越短越好
   │
   └── 10µF ── GND     ← 每个电源域放一个，可以在稍远位置
```

**关键点**：

- 0.1µF 的电容量不是重点，**低 ESL/ESR** 才是（0402 比 0603 好）
- 电容的**地端过孔要就近打**，别绕远
- 大电容（10µF 以上）负责低频，小电容负责高频，两者都要有

**别指望一颗大电容解决问题** —— 100µF 的电解对 10MHz 的噪声几乎没用（ESL 太大）。

## 常见故障对照

| 现象 | 原因 | 处理 |
|---|---|---|
| LDO 烫手、输出掉压 | 功耗超了，进热保护 | 换 Buck 或降低压差 |
| LDO 输出随负载下降 | 压差不够（进了 dropout 区） | 提高输入电压或换低压差型号 |
| 上电时 MCU 反复复位 | LDO 启动慢 / 电池电压低 | 换低压差、加软启动 |
| ADC 读数跳变大 | 数字噪声耦合进模拟电源 | 模拟部分单独 LDO + 磁珠 |
| DC-DC 纹波串到射频 | 共用电源，滤波不足 | 射频单独 LDO，加 π 型滤波 |

## 一份选型速查

| 输入→输出 | 电流 | 方案 |
|---|---|---|
| 24V → 5V | 1A | Buck |
| 12V → 3.3V | 任意 | **必须 Buck** |
| 5V → 3.3V | < 300mA | LDO 可以（0.5W 以内） |
| 5V → 3.3V | > 500mA | Buck（LDO 会烫） |
| 3.7V 锂电 → 3.3V | < 200mA | 低压差 LDO |
| 3.3V → 1.8V | < 300mA | LDO |
| 电池 → 3.3V（要撑到 3.0V） | 任意 | Buck-Boost |

## 小结

判断用 LDO 还是 DC-DC，**先算这一个数**：

```text
P_loss = (Vin − Vout) × Iout
```

- **< 0.5W** → LDO 可以，简单便宜
- **0.5 ~ 1W** → LDO 要选大封装、算好散热
- **> 1W** → 换 Buck，别犹豫

然后再看两个例外：

- **噪声敏感**（ADC / 射频 / 音频）→ 优先 LDO，哪怕效率低
- **输入会低于输出**（锂电放电）→ 必须 Buck-Boost 或低压差 LDO

电源是整块板子的地基。省下一颗 Buck 的钱，可能换来一块会热保护、会掉压、噪声乱窜的板子 —— 这笔账怎么算都不划算。
