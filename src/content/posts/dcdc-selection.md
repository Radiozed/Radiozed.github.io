模块买回来一接就能用，但想做进板子，就必须自己算外围。这篇从拓扑选起，到电感和电容的具体数值。

## 先选拓扑

| 拓扑 | 关系 | 典型场景 |
|---|---|---|
| **Buck（降压）** | Vout < Vin | 12V→5V、24V→3.3V |
| **Boost（升压）** | Vout > Vin | 3.7V 锂电→5V、12V→24V |
| **Buck-Boost（升降压）** | Vout 可高于也可低于 Vin | 电池供电（3.0~4.2V→3.3V） |
| **LDO（线性）** | Vout < Vin，压差小 | 噪声敏感、小电流 |

**选型判断只有两个问题**：

1. 输出电压比输入高还是低？——决定 Buck / Boost
2. 输入电压会不会跨过输出电压？——会就选 Buck-Boost

第三个问题是**效率 vs 噪声**：LDO 没开关噪声但效率 = Vout/Vin，压差大时会烧；DC-DC 效率高但输出有纹波。这篇讲 DC-DC，LDO 放到下一篇。

## Buck 的三个公式

以 12V → 5V / 2A，开关频率 500kHz 为例。

### 占空比

```text
D = Vout / Vin = 5 / 12 ≈ 0.417
```

实际因损耗会略高，可取 0.45 估算。

### 电感

```text
L = (Vin − Vout) × Vout / (Vin × fsw × ΔIL)
```

`ΔIL` 是**电感纹波电流**，一般取输出电流的 **20%~40%**。取 30%：

```text
ΔIL = 2A × 0.3 = 0.6A

L = (12 − 5) × 5 / (12 × 500000 × 0.6)
  = 35 / 3,600,000
  ≈ 9.7 µH   →  选 10 µH
```

**怎么选纹波比例**：

- 取小（20%）→ 电感大、纹波小、成本高
- 取大（40%）→ 电感小、纹波大、可能进 DCM（轻载时）

### 电感饱和电流

这是**最容易烧板子的地方**。电感要满足两个电流指标：

```text
I_sat  > Iout + ΔIL/2   （峰值电流）
I_rms  > Iout           （有效值）
```

上例峰值 = 2 + 0.3 = 2.3A，所以选 **I_sat ≥ 3A** 的电感（留 30% 余量）。

饱和之后电感量骤降，电流瞬间飙升 → 烧 IC 或烧电感。**便宜的功率电感虚标严重，宁可选大一号。**

### 输出电容

```text
ΔVout ≈ ΔIL / (8 × fsw × Cout)
```

要 50mV 纹波：

```text
Cout = 0.6 / (8 × 500000 × 0.05) = 3 µF
```

理论只要 3µF，但实际要 **10~22µF**，因为：

- 陶瓷电容有 **DC bias 效应**：标称 22µF 的 0805 X5R，在 5V 下可能只剩 10µF
- 还要考虑 ESR 带来的纹波

**选型口诀：标称值按算出来的 3~5 倍选，且优先 X7R/X5R，别用 Y5V。**

### 输入电容

容易被忽略，但它决定输入纹波和 EMI：

```text
I_rms ≈ Iout × √(D × (1 − D))
      = 2 × √(0.417 × 0.583) ≈ 0.99 A
```

所以要选**额定纹波电流 ≥ 1.5A** 的电容，通常是 10µF 陶瓷 + 一个 100µF 电解并联。

输入电容**必须紧贴 IC 的 VIN 和 GND 引脚**，这是布局的第一优先级。

## 两个关键参数怎么读手册

### 1. 开关频率

| 频率 | 优点 | 缺点 |
|---|---|---|
| 200~400kHz | 开关损耗小、效率高 | 电感电容大 |
| 500k~1MHz | 体积小 | 开关损耗上升 |
| 2MHz+ | 极小体积 | 效率明显下降，布局要求苛刻 |

小板子选 1~2MHz，效率优先选 300~500kHz。

### 2. 同步整流 vs 非同步

- **非同步**：内部只有高边 MOS，低边用外部肖特基二极管。便宜，但二极管压降 0.3~0.5V，2A 时损耗 0.6~1W
- **同步**：内部高低边都是 MOS，效率高 5~10 个百分点，成本略高

**现在基本都选同步整流**，尤其输出电流 > 1A 时。

### 3. 轻载效率（Iq 与 PFM）

电池设备要注意：很多 DC-DC 在轻载时进入 **PFM（跳周期）模式**省电，但纹波会变大。

如果负载很轻又要低纹波（比如给 ADC 供电），选支持 **强制 PWM 模式**（FPWM）的型号，代价是静态电流上升。

## 布局：90% 的纹波问题在这里

DC-DC 是**唯一一个布局错了就完全不工作**的电路。

### 三条铁律

**① 输入电容紧贴 IC**

```text
    ┌──────────────┐
    │   VIN  GND   │
    └───┬────┬─────┘
        │    │
      ┌─┴─┐ ┌┴─┐        ← 这两个焊盘离引脚 < 2mm
      │CIN│ │CIN│
      └───┘ └──┘
```

输入回路（VIN → 高边 MOS → 电感 → 地 → CIN）的面积要**最小**，这是辐射 EMI 的主要来源。

**② SW 节点面积最小**

SW（开关节点）是电压在 0 和 Vin 之间高速跳变的点，是**最大的噪声源**。

- 走线越短越宽越好
- **不要**在 SW 下面走任何信号线
- 不要为了"好看"把它铺成一大块铜皮

**③ 反馈走线远离 SW**

FB 引脚的分压电阻要靠近 IC，走线**不要从电感和 SW 下方穿过**。噪声耦合进 FB 会导致输出电压抖动甚至振荡。

```text
错误：FB 走线绕到板子另一边，从电感正下方穿过
正确：FB 分压电阻就在 IC 旁边，走线长度 < 5mm
```

### 地怎么处理

**单点接地**：功率地（输入电容地、电感地、输出电容地）和信号地（FB 分压地、IC 的 AGND）在 IC 的 GND 引脚处汇合，其他位置不要连。

多层板直接给完整地平面，靠过孔把 IC 的 GND 焊盘多打几个孔到地平面。

## 常见故障对照

| 现象 | 原因 | 处理 |
|---|---|---|
| 上电就烧 IC | 电感饱和 / 输入电容不够 | 加大电感 I_sat，输入加 100µF |
| 输出纹波巨大（>200mV） | 输出电容 DC bias 失效 / 布局差 | 换大封装电容，重做布局 |
| 空载正常，带载掉压 | 电感 DCR 太大 / 限流 | 换低 DCR 电感 |
| 轻载时啸叫 | 进 PFM 模式，频率落 audible 范围 | 换 FPWM 型号或加大负载 |
| 输出电压随负载漂 | FB 走线被干扰 | 缩短 FB 走线，加 100pF 前馈电容 |
| 效率只有 70% | 用了非同步 + 二极管损耗 | 换同步整流方案 |

## 一份设计检查清单

画完 DC-DC 原理图和 PCB，逐条核对：

```text
□ 电感 I_sat > Iout + ΔIL/2，且留 30% 余量
□ 输出电容按算出来值的 3~5 倍，且是 X7R/X5R
□ 输入电容紧贴 VIN/GND，回路面积最小
□ SW 节点短、宽、无信号线穿越
□ FB 走线 < 5mm，远离电感和 SW
□ 功率地与信号地单点汇合
□ 空载、半载、满载都测过纹波和效率
□ 上电时序（如果有使能脚）验过
```

## 小结

DC-DC 不难，但要**每一条都做对**：

1. **拓扑看压差方向**，跨压差用 Buck-Boost
2. **电感按 ΔIL = 20~40% Iout 算**，饱和电流一定要够
3. **输出电容按算出来值的 3~5 倍**，考虑 DC bias
4. **输入电容紧贴 IC**，这是布局第一优先级
5. **SW 和 FB 是噪声的两端**：一个要小，一个要远

算错一个数，板子还能勉强工作；布局错一步，可能连启动都启动不了。所以打样前多花半小时核对清单，比返工一周划算。
