ESP-01S · MQTT 指令测试

基于 ESP-AT 的 AT+MQTTxxx 指令 · 自动用 CRLF 行尾

默认参数指向公共测试服务器 broker.emqx.io，可直接连。换成你自己的 Broker 时记得改用户名 / 密码。

公共测试服务器，改自己的 Broker 记得填账号密码

属性名必须和 OneNET 控制台「物模型」里的标识符逐字一致，大小写也算。 生成指令时按这里选定的类型拼 JSON：int/float 直接写数字，string 加引号，bool 出 true/false。

指令按 ESP-AT 的顺序发送，每步之间会等待（连 WiFi 12 秒、连 Broker 5 秒）。 日志区显示 ESP-01S 的原始回显，看到 OK 就表示这一步成功。

ESP-01S · 固件烧录

基于 esptool-js · 全程本地，固件不上传

支持 ESP8266 / ESP32 全系。下面按 ESP-01S（1 MB Flash） 预设好了参数，换别的芯片记得改 Flash 大小和烧录地址。

烧之前必须做：ESP-01S 没有自动下载电路，要把 GPIO0 用杜邦线接到 GND，再给模块上电（或者短一下 RST）。 烧完把这根线拔掉重新上电，程序才会正常运行。
供电要 3.3V 且能扛住 500mA，多数 USB-TTL 的 3.3V 引脚带不动，典型症状是"能连上、一写就超时"。
点这里选择 .bin 固件，或者直接把文件拖进来
0% —
  1. 3V3 → 3.3V，GND → GND
  2. TXD → RXD，RXD → TXD（交叉接）
  3. EN（CH_PD）→ 3.3V，否则模块不启动
  4. GPIO0 → GND（只在烧录时接，烧完必须断开）
  1. 停在 Connecting...：没进下载模式，检查 GPIO0 是否真的接地
  2. 反复超时：把波特率降到 115200，或换个供电
  3. 写到一半失败：九成是供电电流不够
  4. 烧完不运行：GPIO0 线还没拔，或 EN 没拉高

固件可以去 ESP-AT Releases 下载，ESP-01S 选 ESP8266-IDF-AT_V…bin（1 MB 版本），地址填 0x0。 想要 AT 指令能连 OneNET，就是烧这个固件。
