校验值用 123456789 测出来的标准结果：CRC-8 = F4、 CRC-16/MODBUS = 4B37、CRC-16/CCITT-FALSE = 29B1、CRC-32 = CBF43926。 如果对不上，说明参数（多项式/初值/反转）选错了。

点击任意一位即可翻转。左边是高位，标号按位权（bit0 在最后）。

分压器

Vout = Vin × R2 / (R1 + R2)。接 ADC 时注意：源阻抗太高会影响采样，一般建议分压后总阻值低于 10 kΩ。

LED 限流电阻

R = (Vcc − Vf) / I。红色 LED 约 1.8–2.0 V，蓝/白约 3.0–3.4 V，普通 IO 建议不超过 10–15 mA。

公式：f = clk / ((PSC+1) × (ARR+1))。工具会自动找误差最小的 PSC/ARR 组合， 并给出实际频率与误差百分比。PWM 频率同理，占空比由 CCR 决定。

反算时直接改上面的参考电压或原始值即可。若接了分压电路，记得把分压比乘回去。
